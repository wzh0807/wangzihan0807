# 网页抓小球小游戏 —— 需求规格说明（spec）

> 课程：《高级网页设计》 | 技术栈：原生 HTML + CSS3 + JavaScript | 日期：2026-10-19

---

## 1. 项目概述

一款网页端「限时抓小球」小游戏。玩家在 2 分钟倒计时内点击页面上随机出现的蓝色小球获取分数，点小球 +2 分、点空白区 −1 分；计时结束后弹出结果面板显示最终得分，可一键重开。

---

## 2. 页面结构

单页面，一个 HTML 文件承载所有结构。自上而下分为三块：

| 区域 | 内容 |
|---|---|
| 顶部状态栏（固定高度，约 50px） | 左边「分数 X」实时更新，右边「剩余 02:00 → 00:00」每秒递减 |
| 游戏区域（占据剩余视窗） | 浅黄色背景、唯一容器，小球在此内绝对定位随机出现 |
| 弹窗（ended 态触发） | 半透明遮罩 + 居中模态面板，显示「游戏结束」、最终分数、「再来一局」按钮 |

`idle` 初始态额外有一个大号「开始游戏」按钮居中于游戏区域。

---

## 3. 三个游戏状态

### 3.1 idle —— 初始态
- 顶部：分数显示 0，倒计时显示固定 `02:00`（**不走计时器**）
- 游戏区域：**不出现小球**（避免未开始就可玩）
- 中央：大号「开始游戏」按钮可点击
- 无弹窗

### 3.2 playing —— 游戏中
- 点击开始按钮后立即进入，**按钮 `display:none` 消失**，不再恢复（重开入口由弹窗接管）
- 小球出现（一个，蓝色圆形，直径 50px）
- 倒计时从 `02:00` 以 mm:ss 格式每秒递减，到 `00:00` 自动转入 ended
- 点击小球：+2 分，小球消失并刷新到新随机位置
- 点击空白区：−1 分，小球不动，位置不变
- 分数**允许变负**（不截断下限）
- 结束瞬间点击保护：小球 handler 先判断 `gameState === 'playing'` 才执行加分和刷新

### 3.3 ended —— 结束态
- 计时器停止（清除 interval）、分数冻结、小球隐藏
- 半透明黑色遮罩层覆盖整页
- 居中模态面板（圆角、白背景）包含：「游戏结束」标题、最终分数、「再来一局」按钮
- 点击「再来一局」：重置分数为 0、倒计时重置回 `02:00`、关闭弹窗、生成第一个小球、进入 playing 态

---

## 4. 小球行为

| 项 | 规格 |
|---|---|
| 视觉 | 纯蓝圆形（推荐 `#2E86DE`），直径 50px，细白描边，轻微 drop-shadow |
| 数量 | 始终一个，点掉才刷新 |
| 位置 | 绝对定位；`left` 和 `top` 基于游戏区域可视范围计算，保证 50px 小球完整落在区域内；刷新时**排除当前位置**避免原地重复 |
| 寿命 | 无自动消失机制，持续存在直到被点击（或游戏结束） |

---

## 5. 点击判定与事件冒泡

核心逻辑：点击小球 +2 且刷新位置；点击空白 −1 且小球不动。

实现要点：
- 小球 click handler 内先判断 `gameState !== 'playing'` 则直接 return
- 父容器（游戏区域）click handler 内用 `if (e.target !== gameArea) return;` 过滤——只有真正点到空背景才减分，冒泡上来的小球点击会被排除

---

## 6. 顶部状态栏

- 固定在页面顶部，flex 布局左右两端对齐
- 左边：「分数 X」，加粗，字号 ≥ 18px
- 右边：「剩余 mm:ss」，加粗，与左边对齐
- 浅黄背景（页面同色），文本用深色保证对比度

---

## 7. 计时逻辑

- 总时长：**120 秒**
- playing 态内每秒 `setInterval` 递减 `timeLeft`
- 显示格式 `mm:ss`，个位数补零（`padStart(2, '0')`）
- `timeLeft` 到 0 时清除 interval，切换到 ended

---

## 8. 文件结构（按课程原生三文件）

```
/
├── index.html      # 页面结构（状态栏、游戏区域、弹窗）
├── style.css       # 全部样式（浅黄色背景、小球、弹窗、状态栏、按钮）
└── script.js       # 全部逻辑（状态机、计时器、小球、点击判定、事件处理）
```

无外部依赖、无 CDN、无构建工具。

---

## 9. 核心状态变量（script.js）

| 变量 | 类型 | 说明 |
|---|---|---|
| `gameState` | `'idle' \| 'playing' \| 'ended'` | 当前状态，驱动 UI 和 handler 分支 |
| `score` | number | 当前分数，初始 0 |
| `timeLeft` | number | 剩余秒数，初始 120 |
| `timerId` | number\|null | `setInterval` 返回值，ended 时 `clearInterval` 用 |
