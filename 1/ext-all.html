任务一：提示词工程（缺陷 vs 完善实跑对比）｜任务二：creative 仿写｜任务三：综合创作 + keyboard 超纲。每个任务都按「提示词 → 配置代码 → 需求参数对照表 → 实跑演示」组织。

任务一 · 提示词工程师（让 AI 听懂需求）⭐⭐

目标产物是一段 new Swiper(...) 配置，须满足 4 条需求：①无缝循环 ②3.2 秒自动翻页且手动后不停止 ③圆点可点击 ④初始效果 cube。

第 1 轮提示词
帮我写一段 Swiper 11 的初始化代码，容器是 #wzh_demo，要求无缝循环、每 3.2 秒自动翻页，底部圆点分页器，初始切换效果用 cube。
第 2 轮提示词（发现缺陷后补说）
上一轮有两个问题：1）autoplay 默认在用户交互后会停止，我要"手动操作后自动播放不停止"；2）圆点分页器必须能点击直接跳转，不能只显示。请按四条需求逐条对应，重新输出完整配置。

第 1 轮 · 缺陷圆点只能看，不能点

只写了"圆点分页器"，AI 理解为"把圆点画出来"，没给 clickable；autoplay 也漏了"手动后不停止"。试试：拖一下，它就不再自己翻了。

需求（中文）对应参数为什么是它
① 无缝循环loop: true最后一张再往后翻直接回第一张，不卡住不留白。
② 3.2 秒自动翻页，手动后不停止autoplay: { delay: 3200, disableOnInteraction: false }delay 单位是毫秒；默认交互后自动播放会停，必须显式关掉。
③ 圆点分页器可点击pagination: { el: '…', clickable: true }只写 el 圆点只是"显示器"，加 clickable 才是"遥控器"。
④ 初始效果为 cubeeffect: 'cube'不写 effect 默认是平推 slide，题目指定 3D 立方体。

任务二 · creative 仿写（transform 自由组合）

creativeEffect.prev 控制离场那张：缩小左移带 -12° 倾角与阴影；creativeEffect.next 控制入场那张：从右侧 100% 进场。

给 AI 的提示词
用 Swiper 11 的 creative 效果初始化 #wzh_esw1：要求循环播放、切换 800ms；离场那张（prev）缩小左移 20%、带 -12° 倾角和阴影，入场那张（next）从右侧 100% 进场；保留可点击的圆点分页器 #wzh_epag1。注意 creative 不是预设效果，要用 creativeEffect 分别描述 prev 和 next 的 transform。
new Swiper('#wzh_esw1', { loop: true, speed: 800, effect: 'creative', creativeEffect: { prev: { shadow: true, translate: ['-20%', 0, -1], rotate: [0, 0, -12] }, next: { translate: ['100%', 0, 0] } }, pagination: { el: '#wzh_epag1', clickable: true } });
想要的效果（中文）对应参数为什么是它
上一张缩小后往左退、带阴影prev: { shadow: true, translate: ['-20%', 0, -1] }x 方向 -20% 左移、z 轴 -1 压到下层、shadow 加投影。
离场时带一点倾斜prev.rotate: [0, 0, -12]rotate 三参数是 [x轴, y轴, z轴] 角度，z 轴 -12° 即平面内倾斜。
下一张从右侧入场next: { translate: ['100%', 0, 0] }next 描述"入场"那张：从右 100% 位置推进来。

任务三 · 综合创作 + keyboard 键盘导航

六件展品（新增爱达魔都号——2024 年 1 月首航，国产大型邮轮），并启用 keyboard 模块，方向键 ← → 在任意焦点下翻页。

给 AI 的提示词
把轮播扩充到六张 slide，第六张是"爱达魔都号——2024 年 1 月首航，国产大型邮轮"；保留可点击圆点分页器 #wzh_epag2，并启用 keyboard 键盘导航，要求方向键在页面任意焦点下都能翻页（不只焦点在轮播上时）。
new Swiper('#wzh_esw2', { loop: true, speed: 600, keyboard: { enabled: true, onlyInViewport: false }, pagination: { el: '#wzh_epag2', clickable: true } });
想要的效果（中文）对应参数为什么是它
方向键 ← → 翻页keyboard: { enabled: true }keyboard 是独立模块，不写的话按键毫无反应。
焦点不在轮播上按键也生效onlyInViewport: false默认 true 时轮播滚出视口按键就失效，本页有多个轮播必须关掉。
