二

creative 仿写transform 自由组合：translate + rotate + shadow

creativeEffect.prev 控制离场那张：缩小左移 translate:['-20%',0,-1]、带 rotate:[0,0,-12] 倾角与阴影；creativeEffect.next 控制入场那张：从右侧 translate:['100%',0,0] 放大进场。translate 三参数是 [x%, ypx, z 透视]。

✍️ 扩展任务二 要求

初始化 #wzh_esw1 为 creative 效果：prev 缩小左移带阴影和 -12° 倾角，next 从右 100% 入场，循环播放，保留圆点分页器。

⭐ 验证标准：上一张缩小后往左退、下一张从右入场，像电影镜头的"拉远/推进"
给 AI 的提示词
用 Swiper 11 的 creative 效果初始化 #wzh_esw1：要求循环播放、切换 800ms；离场那张（prev）缩小左移 20%、带 -12° 倾角和阴影，入场那张（next）从右侧 100% 进场；保留可点击的圆点分页器 #wzh_epag1。注意 creative 不是预设效果，要用 creativeEffect 分别描述 prev 和 next 的 transform。
new Swiper('#wzh_esw1', { loop: true, speed: 800, effect: 'creative', creativeEffect: { prev: { shadow: true, translate: ['-20%', 0, -1], rotate: [0, 0, -12] }, next: { translate: ['100%', 0, 0] } }, pagination: { el: '#wzh_epag1', clickable: true } });
想要的效果（中文）对应参数为什么是它
上一张缩小后往左退、带阴影prev: { shadow: true, translate: ['-20%', 0, -1] }prev 描述"离场"那张：x 方向 -20% 左移、z 轴 -1 压到下层、shadow 加投影。
离场时带一点倾斜prev.rotate: [0, 0, -12]rotate 三参数是 [x轴, y轴, z轴] 角度，z 轴 -12° 就是平面内倾斜。
下一张从右侧入场next: { translate: ['100%', 0, 0] }next 描述"入场"那张：从右 100% 位置推进来。
圆点能点击跳页pagination: { clickable: true }与实验一同一教训：只写 el 圆点只是显示器。

三

综合创作 + keyboard 键盘导航六件展品 · 方向键 ← → 翻页

① 展品扩充：第六件展品"爱达魔都号——2024 年 1 月首航，国产大型邮轮，中国造船史上的里程碑"。② 超纲能力：启用 keyboard 模块，onlyInViewport:false 让方向键在任意焦点下生效。③ 新增功能：3.2 秒自动轮播（手动后不停）、播放/暂停按钮、可拖动滚动条。

✍️ 扩展任务三 要求

初始化 #wzh_esw2：六张 slide（含爱达魔都号），保留 #wzh_epag2 圆点分页器，加 keyboard、3.2 秒 autoplay、可拖动 scrollbar、播放/暂停按钮。

⭐ 验证标准：方向键 ← → 能翻页；点"暂停"后自动播放停止；拖底部滚动条能跳页
给 AI 的提示词
把轮播扩充到六张 slide，第六张是"爱达魔都号——2024 年 1 月首航，国产大型邮轮"；保留可点击圆点分页器 #wzh_epag2；启用 keyboard 键盘导航（方向键在任意焦点下翻页）；开启 3.2 秒自动播放且用户操作后不停止；在底部加可拖动滚动条 #wzh_esbar2；再放一个播放/暂停按钮 #wzh_play2，点击时调用 swiper.autoplay.start()/stop() 并切换按钮文字。
var wzh_esw2 = new Swiper('#wzh_esw2', { loop: true, speed: 600, autoplay: { delay: 3200, disableOnInteraction: false }, keyboard: { enabled: true, onlyInViewport: false }, pagination: { el: '#wzh_epag2', clickable: true }, scrollbar: { el: '#wzh_esbar2', draggable: true } }); document.getElementById('wzh_play2').addEventListener('click', function(){ if (wzh_esw2.autoplay.running) { wzh_esw2.autoplay.stop(); this.textContent = '▶ 播放'; } else { wzh_esw2.autoplay.start(); this.textContent = '⏸ 暂停'; } });
想要的效果（中文）对应参数为什么是它
方向键 ← → 翻页keyboard: { enabled: true }keyboard 是独立模块，不写的话按键毫无反应。
焦点不在轮播上按键也生效onlyInViewport: false默认 true 时轮播滚出视口按键就失效，本页有两个轮播必须关掉。
3.2 秒自动轮播，手动后不停autoplay: { delay: 3200, disableOnInteraction: false }与任务一同一教训：默认交互后会停，必须显式关掉。
底部可拖动滚动条scrollbar: { el: '…', draggable: true }只加 DOM 还不够，要 draggable:true 才能用鼠标拖。
播放/暂停按钮JS 监听 click → autoplay.start()/stop()按钮不是 Swiper 内置，得自己绑事件并切换文字。
